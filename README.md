# Анонсы лицея — MVP Telegram-бота

Простой бот-лента для объявлений лицея:

- `/start` — главное меню;
- **«Читать»** — анонсы по одному, с кнопками **«Новее»** / **«Старше»**;
- **«Написать»** — пользователь отправляет текст, и тот сразу появляется в ленте;
- все анонсы хранятся в локальной SQLite-базе;
- никаких внешних серверов и платных сервисов не нужно.

## Как запустить (Windows)

Нужен Python 3.10 или новее. Проверено на Python 3.14.

1. Открой PowerShell в папке проекта:

   ```powershell
   cd "путь\к\liceum_anons_bot"
   ```

2. Создай виртуальное окружение и установи зависимости:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   python -m pip install -r requirements.txt
   ```

   Если PowerShell не разрешает активацию, можно не активировать окружение,
   а запускать всё через его Python:

   ```powershell
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   .\.venv\Scripts\python.exe bot.py
   ```

3. Получи токен у [@BotFather](https://t.me/BotFather):
   `/newbot` → название → username → токен вида `123456789:AA...`.

4. Скопируй `.env.example` в `.env` и вставь токен:

   ```powershell
   Copy-Item .env.example .env
   notepad .env
   ```

   Внутри должно быть примерно так:

   ```dotenv
   BOT_TOKEN=123456789:AA...твой_токен...
   TIMEZONE=Europe/Moscow
   DB_PATH=data/announcements.db
   ```

5. Запусти бота:

   ```powershell
   python bot.py
   ```

   В консоли появится `Бот запущен`. Открой своего бота в Telegram и отправь `/start`.

Остановить бота — `Ctrl+C` в консоли.

## Настройки

| Переменная | Обязательна | По умолчанию | Что делает |
|---|---|---|---|
| `BOT_TOKEN` | да | — | Токен от @BotFather |
| `TIMEZONE` | нет | `Europe/Moscow` | Часовой пояс для даты анонса |
| `DB_PATH` | нет | `data/announcements.db` | Путь к файлу SQLite |

Примеры часовых поясов: `Europe/Kaliningrad`, `Europe/Moscow`,
`Asia/Yekaterinburg`, `Asia/Novosibirsk`, `Asia/Vladivostok`.

## Как устроено

```text
liceum_anons_bot/
├── bot.py              # запуск, команды и inline-кнопки
├── config.py           # чтение .env
├── db.py               # SQLite и выборка соседних анонсов
├── ui.py               # тексты, форматирование и клавиатуры
├── tests/              # тесты базы и форматирования
├── requirements.txt
├── .env.example
└── README.md
```

Навигация не использует «номер страницы»: кнопки запоминают ID соседнего
анонса. Поэтому лента не ломается, когда кто-то публикует новый анонс, пока
другой человек читает старые.

Текст пользователя экранируется перед отправкой как HTML, поэтому символы
вроде `<` и `&` не ломают сообщение.

## Проверка

```powershell
python -m unittest discover -s tests -v
```

Тесты используют временную базу и не обращаются к Telegram.

## Что пока не входит в MVP

Это первая версия, в ней намеренно нет:

- лайков и дизлайков;
- модерации и админ-панели;
- удаления и редактирования анонсов;
- фото, видео и других вложений;
- ограничения частоты публикаций и защиты от спама;
- ограничения доступа: писать может любой, у кого есть бот.

Перед реальным запуском в лицее это важно учесть: сейчас любой пользователь
бота может опубликовать что угодно, и анонс сразу виден всем. Для закрытого
пилота можно раздать бота ограниченному кругу людей либо сначала добавить
модерацию.

## Куда расширять дальше

- **Лайки/дизлайки.** Таблица `reactions(announcement_id, user_id, value)` с
  уникальной парой `(announcement_id, user_id)`; callback-кнопки
  `reaction:like:<id>` и `reaction:dislike:<id>`, затем обновление счётчиков
  в тексте анонса.
- **Модерация.** В таблице уже есть поле `status` со значениями
  `pending` / `published` / `rejected`. Можно отправлять новые анонсы
  администраторам с кнопками «Опубликовать» / «Отклонить» и показывать в ленте
  только `published`.
- **Админы.** Список ID из переменной окружения `ADMIN_IDS`; отдельный роутер
  с командами и проверкой `user_id`.
- **Редактирование / удаление.** Хранить `author_id` (уже хранится) и давать
  автору или модератору кнопки управления своим анонсом.
- **Медиа.** Хранить `file_id` и тип вложения рядом с текстом и отправлять
  соответствующим методом Telegram.
- **Антиспам.** Проверка времени последней публикации автора и/или лимит
  анонсов в час.

## Частые проблемы

**`Не задан BOT_TOKEN`** — файл `.env` не создан или токен не вставлен.

**`Unauthorized`** — токен неверный или был перевыпущен в @BotFather.

**Бот не отвечает** — процесс `python bot.py` должен быть запущен; проверь
интернет и вывод консоли.

**Хочу очистить ленту** — останови бота и удали `data/announcements.db`
(файлы `-wal` и `-shm` тоже можно удалить).
